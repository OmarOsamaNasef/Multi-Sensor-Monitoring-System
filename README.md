# Multi Sensor Monitoring System

Arduino-based system for monitoring environmental conditions using multiple sensors.

## Features
- Water level detection
- Fire detection
- Distance measurement
- LCD display
- Bluetooth monitoring
- Alarm system

## Components
- Arduino UNO R3
- Arduino power cable
- Breadboard
- Bluetooth Module (HC-05/HC-06)
- Flame Sensor
- Ultrasonic Sensor (HC-SR04)
- Water Sensor
- Water Pump (optional)
- LEDs
- Resistors 220Ω
- Buzzer
- Connecting wires
- LCD 16x2 with I2C module

## Description
This project is designed to monitor water level, detect fire, and measure distance using Arduino sensors. The system displays sensor data on LCD and sends alerts through buzzer and Bluetooth communication.
